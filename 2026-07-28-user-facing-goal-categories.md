# User-Facing Goal Categories

These are brainstorming ideas for a possible goal-oriented navigation layer. They
are not approved tags, and no taxonomy or resource metadata changes should be
made from this list yet.

## Current Ideas

1. **Board Preparation**
   - Written and oral board preparation.
   - Could draw from the existing `board-preparation` tag.

2. **Contouring & Treatment Planning**
   - Contouring practice, atlases, constraints, and planning resources.
   - Could group the existing `contouring` and `treatment-planning` tags.

3. **Case Preparation**
   - Originally proposed for preparing for clinic, new patients, tumor boards,
     and case presentations.
   - This framing does not currently feel intuitive and should be reconsidered
     or replaced.

4. **On-Call**
   - Emergencies, urgencies, and practical on-call preparation.
   - This seems promising as a user goal, but no `on-call` tag should be added
     until the idea has been considered further.

5. **Foundational Sciences**
   - Physics and radiobiology learning or review.
   - Statistics is not a significant enough portion of the current collection
     to warrant a dedicated tag or emphasis here.

6. **Staying Current with Literature**
   - Journal discussions, journal clubs, podcasts, newsletters, and other
     literature updates.
   - The existing `literature-review` tag is broad enough to include literature
     updates and should not be renamed.

7. **Resident Orientation**
   - Orientation and getting started as a new radiation oncology resident.
   - Could draw from introductory resources and the `resident` audience.

8. **Professional Development**
   - Career development, academic medicine, research, and leadership.
   - `research-methods` should not be introduced because research methodology
     is not a significant portion of the current collection.

## Current Decisions

- Keep these as brainstorming concepts rather than tags.
- Do not add `case-preparation`.
- Do not add `on-call` yet.
- Do not add `research-methods`.
- Do not add or emphasize `statistics`.
- Keep `literature-review` as the existing umbrella tag.
